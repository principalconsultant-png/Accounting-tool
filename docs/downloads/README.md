# User guide and sales receipt templates

Version 0.29.1-dev. These small documentation/template files are stored on the development branch so readers do not need expiring chat URLs or a GitHub Actions artifact download. No release or main merge is involved.

Download the ZIP using its Raw/Download raw file button, or download each PDF/XLSX/CSV separately. The ZIP contains the printable guide, its editable Markdown source and both blank templates. It includes the verified-backup clean-books instructions.

Generated with scripts/build_user_manual.py from the tested 0.29.1-dev source. Template has 28 columns; the Excel Receipts sheet is empty by design. Review Instructions before importing.
