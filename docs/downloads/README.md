# Yathartha user guide and receipt templates

Current version: 0.30.0-dev. Download Yathartha-0.30.0-Guide-and-Templates.zip for the updated PDF, editable source, blank templates and verified worked-example source/reports.

The guide explains calendar controls, the visible editable Vendor master, rejecting duplicates before confirming/approving valid receipts, and named journal previews. Its complete daily-sales-to-financial-reports walkthrough and practice files are included. Examples are TRAINING ONLY, not live transactions.

Existing RijuBooks-prefixed PDF/template filenames and older ZIPs remain for download-link compatibility. The current application display is यथार्थः / Yathartha and executable is Yathartha.exe. Existing Windows book paths are unchanged. Documentation is stored on the development branch to avoid expiring chat URLs; no release/main merge is involved.
