# Yathartha user guide and receipt templates

Current version: 0.32.1-dev. Download Yathartha-0.32.1-Guide-and-Templates.zip for the updated PDF, editable source, blank templates and verified worked-example source/reports.

The guide explains calendar controls, the visible editable Vendor master, rejecting duplicates before confirming/approving valid receipts, and named journal previews. Its complete daily-sales-to-financial-reports walkthrough and practice files are included. Examples are TRAINING ONLY, not live transactions.

Existing RijuBooks-prefixed PDF/template filenames and older ZIPs remain for download-link compatibility. The current application display is यथार्थः / Yathartha and executable is Yathartha.exe. Existing Windows book paths are unchanged. Documentation is stored on the development branch to avoid expiring chat URLs; no release/main merge is involved.

Regular account lookup: Yathartha-Account-Posting-Reference.pdf contains a five-page printable code/use/JE reference, including pharmacy inventory versus medicine cost of sales, vendor payment, daily receipts, provider settlement, normal expenses and tax/control lookups. Source is docs/ACCOUNT_POSTING_REFERENCE.md.

Bulk AP invoice templates: Yathartha-AP-Bulk-Invoices-Template.xlsx and .csv mirror manual AP entry, including the optional existing accrual voucher. The Excel template has date formats, lookup sheets and instructions. Export from the app for your current vendor/account lists. See Chapter 27 in the updated guide.

Chapter 28 covers T-form balance sheets and embedded client-left/AXIOM-right report logo setup, replacement and PDF/Excel exports. Actual client/AXIOM images must be selected locally.

AP bulk review now highlights invalid/duplicate rows and keeps the source-row reason and original entered values visible. Chapter 27 explains source corrections versus master revalidation.
